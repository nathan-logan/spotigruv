# Changelog

## v1.0.0 (2026-10-14)

First release of Spotigruv: a Gruvbox dark theme for [Spotifast](https://github.com/crmne/spotifast).

### Added

- `Gruvbox Dark.json` theme, built on Spotifast's `dark` base
- Warm Gruvbox backgrounds, from `#282828` for the window through to `#504945` for selected items
- Cream `#ebdbb2` text, with muted `#a89984` and `#928374` for secondary and dimmed text
- Gruvbox orange `#fe8019` accent
- Gruvbox red and yellow for errors and warnings
- README with install steps, a full palette table, and other accent colours you can swap in

### Install

```sh
cp "Gruvbox Dark.json" ~/.config/spotifast/themes/
```

Restart Spotifast and pick **Gruvbox Dark** in the theme settings. Turn off **accent from album art** to keep the orange accent.
